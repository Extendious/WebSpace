HTML Track: Core Structure

Structure Phase

Step 1: Basic Structure

<!DOCTYPE html><html><head><title>My Planet</title></head><body><h1>Welcome to Earth</h1></body></html>

Step 2: Headings (h1 - h6)

<h1>Heading 1</h1><h2>Heading 2</h2><h3>Heading 3</h3>

Step 3: Paragraphs & Text Format

<p>Paragraph 1: Exploring deep space.</p><p>Paragraph 2: Cadet log updated.</p>

Step 4: Hyperlinks & Anchors

<a href="https://google.com" target="_blank">Launch to Google</a>

Step 5: Displaying Images

<img src="https://via.placeholder.com/150" alt="Space Satellite">

Step 6: Unordered Bullet Lists

<ul><li>Oxygen Tank</li><li>Fuel Cell</li><li>Space Suit</li></ul>

Step 7: Ordered Numbered Lists

<ol><li>Ignite Thrusters</li><li>Break Gravity</li><li>Enter Orbit</li></ol>

Step 8: Div Section Containers

<div style="background:#1a0033; padding:15px; border:1px solid #00f0ff;"><h3>Inside Container</h3></div>

Step 9: Inline Span Tags

<p>Systems are <span style="color:#00f0ff;">Operational</span>.</p>

Step 10: Interactive Buttons

<button onclick="alert('System Check Passed!')">Run Diagnostics</button>

CSS Track: Nebula Styling

Styling Phase

div { background: linear-gradient(#1a0033, #0a0a1f); padding: 20px; color: #fff; }

Step 17: Internal Padding

button { background: #00f0ff; border:none; padding:10px 20px; transition: 0.3s; } button:hover { background: #ff00aa; color: #fff; }
