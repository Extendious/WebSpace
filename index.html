HTML Track: Structure & Core Tags (Missions 1–10)

Structure Phase • 10 Lessons

Mission 1: Document & <h1> Heading

What it is: <h1> is the primary Level 1 heading tag inside an HTML document.

What it's used for: Displaying the main title or top headline of a page or mission.

How it works: As a block-level element, it starts on a new line, spans the available width, and uses large default heading styling.

<!DOCTYPE html> <html> <head><title>My Planet</title></head> <body><h1>Welcome to Earth</h1></body> </html>

Mission 2: Headings (<h1>–<h6>) & Paragraphs (<p>)

What it is: Heading tags (<h1> to <h6>) set title levels, while <p> defines a text paragraph.

What it's used for: Structuring sections from main titles to subheadings and body paragraphs.

How it works: Each element renders as a separate block with built-in vertical spacing; smaller numbers mean higher importance/size.

<h1>Main Sector</h1> <h2>Sub-Sector</h2> <p>Cadet log entry.</p>

Mission 3: Multiple Paragraphs (<p>)

What it is: <p> is the standard HTML paragraph element for blocks of prose.

What it's used for: Separating distinct thoughts, explanations, or stories on a page.

How it works: Browsers automatically place vertical margin between consecutive <p> tags so text doesn't clump together.

<p>Paragraph 1: Exploring deep space.</p> <p>Paragraph 2: Cadet log updated.</p>

Mission 4: Hyperlinks (<a> and href)

What it is: <a> is the anchor tag, and href specifies the destination URL or path.

What it's used for: Navigating between pages, sections, or external websites.

How it works: Clicking the text inside <a href="..."> tells the browser to load that target address.

<a href="https://example.com" target="_blank">Launch Link</a>

Mission 5: Images (<img>, src, and alt)

What it is: <img> is a self-closing element that embeds pictures using src and describes them with alt.

What it's used for: Showing visual media, icons, or diagrams while keeping accessibility and fallback text.

How it works: The browser fetches the image file from src and displays alt text if the image fails to load or for screen readers.

<img src="https://via.placeholder.com/150" alt="Space Satellite">

Mission 6: Unordered Lists (<ul> and <li>)

What it is: <ul> creates an unordered list container holding <li> (list item) entries.

What it's used for: Grouping items where sequence or ranking does not matter, like supply checklists.

How it works: Each <li> inside <ul> is rendered on its own line with a bullet marker by default.

<ul> <li>Oxygen Tank</li> <li>Fuel Cell</li> </ul>

Mission 7: Ordered Lists (<ol> and <li>)

What it is: <ol> creates a numbered/ordered list container around <li> items.

What it's used for: Step-by-step instructions, rankings, or sequences where order matters.

How it works: The browser automatically numbers each <li> in ascending order (1, 2, 3...).

<ol> <li>Ignite Thrusters</li> <li>Enter Orbit</li> </ol>

Mission 8: Block Containers (<div>)

What it is: <div> is a generic block-level container used to group HTML elements together.

What it's used for: Wrapping sections, cards, or layouts so you can style or position them as a unit.

How it works: It has no special semantic meaning on its own and spans full width by default until styled with CSS.

<div style="background:#1a0033; padding:12px;">Mission Box</div>

Mission 9: Inline Containers (<span>)

What it is: <span> is a generic inline container for small pieces of text or elements inside a line.

What it's used for: Highlighting a specific word or phrase inside a sentence without breaking the line.

How it works: Unlike <div>, a <span> stays inline with surrounding text and only takes the width of its content.

<p>Status: <span style="color:#00f0ff;">Nominal</span></p>

Mission 10: Interactive Buttons (<button>)

What it is: <button> is a clickable HTML control element for user actions.

What it's used for: Triggering actions like submitting forms, opening menus, or running JavaScript functions.

How it works: When clicked, the browser fires a click event that can run an inline or external JavaScript handler.

<button onclick="alert('Diagnostics OK!')">Run Check</button>

CSS Track: Styling & Layout (Missions 11–20)

Styling Phase • 10 Lessons

Mission 11: Text & Background Colors (color & background-color)

What it is: color sets foreground text color, while background-color fills the element's background.

What it's used for: Establishing visual themes, contrast, and readability across sections.

How it works: CSS matches a selector and applies hex, RGB, or named color values to the text or background area.

.demo-11 { background-color: #0a0a1f; color: #00f0ff; padding: 10px; }

Mission 12: Text Glow & Shadows (text-shadow)

What it is: text-shadow applies shadow offset, blur, and color effects to text glyphs.

What it's used for: Adding neon glow, depth, or separation over bright or dark backgrounds.

How it works: Values follow x-offset y-offset blur-radius color; zero offsets with blur create a centered halo.

.demo-12 { color: #fff; text-shadow: 0 0 10px #ff00aa; }

Mission 13: Gradients (linear-gradient)

What it is: linear-gradient() creates a smooth color transition along a straight line as a background image.

What it's used for: Blending two or more colors seamlessly into headers, banners, or cards.

How it works: The browser interpolates intermediate color stops smoothly from the start color to the end color.

.demo-13 { background: linear-gradient(90deg, #1a0033, #0088aa); padding: 12px; color: #fff; }

Mission 14: Borders (border)

What it is: border draws an outline around an element's padding box.

What it's used for: Framing cards, separating boxes, or highlighting active/focused elements.

How it works: Shorthand syntax combines width style color (such as 2px solid #00f0ff) around all four sides.

.demo-14 { border: 2px solid #00f0ff; padding: 10px; }

Mission 15: Rounded Corners & Circles (border-radius)

What it is: border-radius rounds the corners of an element's box.

What it's used for: Softening sharp corners on buttons/cards or turning an equal square into a circle (50%).

How it works: The browser curves each corner using the specified pixel or percentage radius.

.demo-15 { width: 60px; height: 60px; background: #ff00aa; border-radius: 50%; }

Mission 16: Outer Spacing (margin)

What it is: margin creates transparent space outside an element's border.

What it's used for: Pushing neighboring elements or sections apart so they aren't touching.

How it works: It expands the external clearance around the box; vertical margins between block elements can collapse.

.demo-16 { margin: 20px; background: #1a0033; padding: 10px; }

Mission 17: Inner Spacing (padding)

What it is: padding creates space between an element's content and its border.

What it's used for: Giving text or buttons comfortable breathing room inside their container.

How it works: Unlike margin, padding sits inside the box and shows the element's background color.

.demo-17 { padding: 24px; background: #1a0033; border: 1px solid #00f0ff; }

Mission 18: Hover States (:hover)

What it is: :hover is a CSS pseudo-class that applies styles when the pointer is over an element.

What it's used for: Giving interactive visual feedback on buttons, links, and cards.

How it works: When the user moves the cursor onto the selector, the :hover rules activate until the cursor leaves.

<style>.btn-18:hover { background: #ff00aa; color: #fff; }</style> <button class="btn-18">Hover Me</button>

Mission 19: Font Family & Font Size (font-family & font-size)

What it is: font-family selects the typeface, and font-size controls how tall the text appears.

What it's used for: Matching your design tone (such as clean UI or monospace code) and establishing visual hierarchy.

How it works: The browser tries fonts in font-family from left to right and sizes characters using units like px, rem, or em.

.demo-19 { font-family: monospace; font-size: 20px; color: #00ff66; }

Mission 20: Flexbox Alignment (display: flex)

What it is: display: flex turns a container into a flexible layout box for its direct children.

What it's used for: Aligning items in a row or column, centering content, and distributing spacing evenly.

How it works: Flex items line up along a main axis and cross axis and can be spaced with properties like justify-content and gap.

.demo-20 { display: flex; justify-content: center; gap: 12px; }

JavaScript Track: Logic & Interactivity (Missions 21–30)

Interactivity Phase • 10 Lessons

Mission 21: Functions & alert()

What it is: A function groups executable code, and alert() shows a simple browser popup message.

What it's used for: Running a block of logic on demand, such as when a cadet clicks a launch button.

How it works: Declaring a function stores the instructions; calling it runs each statement inside { }.

function launch() { alert("Rocket launched! 🚀"); }

Mission 22: Changing Text with DOM (getElementById & innerText)

What it is: document.getElementById() selects an element by id, and innerText updates its visible text.

What it's used for: Dynamically updating labels, statuses, or scores without reloading the webpage.

How it works: JavaScript finds the matching element in the Document Object Model (DOM) and replaces its text string.

document.getElementById('st-22').innerText = 'Thrusters active!';

Mission 23: Console Debugging (console.log())

What it is: console.log() prints values or messages to the browser's developer console.

What it's used for: Checking variable values, tracing code flow, and spotting bugs while building.

How it works: It writes output into the DevTools console (opened with F12) without interrupting the user's page view.

console.log("Telemetry received!");

Mission 24: Variables (let)

What it is: let declares a block-scoped variable that can store and update a value.

What it's used for: Holding changing data like scores, star counts, or user input.

How it works: let score = 100; reserves a named value in memory that can be reassigned later (e.g., score = 110).

let score = 100; alert("Score: " + score);

Mission 25: Changing Styles via JS (.style)

What it is: Accessing element.style lets JavaScript read or modify inline CSS properties.

What it's used for: Changing colors, visibility, or highlights dynamically in response to user actions.

How it works: Hyphenated CSS names become camelCase in JS (like backgroundColor) and apply directly to the element.

document.getElementById('box-25').style.backgroundColor = '#00f0ff';

Mission 26: Arithmetic & Calculations (+, -, *, /)

What it is: Arithmetic operators perform math on numbers in JavaScript.

What it's used for: Calculating totals, percentages, progress bars, or game points.

How it works: Expressions evaluate using standard math precedence and return a numeric result.

let totalFuel = 50 + 75; alert("Total Fuel: " + totalFuel);

Mission 27: Conditional Decisions (if / else)

What it is: An if / else statement chooses between two code paths based on a true/false condition.

What it's used for: Checking conditions like whether a quiz answer is right or if stars reached the goal.

How it works: If the condition inside ( ) evaluates to true, the if block runs; otherwise, the else block runs.

let fuel = 20; if (fuel > 50) { alert("Ready"); } else { alert("Low Fuel!"); }

Mission 28: Arrays ([])

What it is: An array is an ordered list of values enclosed in square brackets [ ].

What it's used for: Storing collections like a list of planets, missions, or quiz options.

How it works: Arrays use zero-based indexing, so the first item is at index 0, the second at 1, and so on.

let planets = ['Earth', 'Mars', 'Jupiter']; alert(planets[1]);

Mission 29: Loops (for)

What it is: A for loop repeats a block of code a set number of times.

What it's used for: Generating repeated items, counting down, or stepping through lists automatically.

How it works: It runs an initializer once, checks a stop condition before each pass, and updates a counter after each pass.

for (let i = 1; i <= 3; i++) { console.log("Countdown: " + i); }

Mission 30: Star Achievement & Progress Logic

What it is: Combining state variables, DOM updates, and threshold checks to track star achievements.

What it's used for: Awarding stars when cadets learn/answer correctly and unlocking milestones or certificates at target goals.

How it works: Incrementing a star counter updates both the star badge display and progress bar percentage, triggering an achievement alert when the 30-star goal is met.

stars = Math.min(30, stars + 1); if (stars === 30) alert("Star Achievement Unlocked!");
